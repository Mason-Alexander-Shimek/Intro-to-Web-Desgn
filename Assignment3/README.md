# Intro to Web Design

This is my root repository for my Intro to Web Design course. Each module gets
its own assignment folder.

| Folder | Module | What it covers |
| --- | --- | --- |
| [Assignment1](Assignment1) | 1 | HTML structure, semantic elements, lists, links and images |
| [Assignment2](Assignment2) | 2 | CSS styling and a navigation component across four pages |
| [Assignment3](Assignment3) | 3 | `<div>` containers, classes, and reusable hero and card components |

All three build the same project: a lore reference for the cyberpunk tabletop
campaign I run, set in a Moscow owned by the Orihia Corporation.

Thanks for visiting.
