Missoula Resource Finder, Page Wireframes

One wireframe per proposed page: a start page that routes by need, plus four category pages. Every block is a named component. Tags mark which layout system holds it together. Drawn at phone width first, because the proposal promises phone-first.

  • FLEX one-dimensional row or column
  • GRID two-dimensional
  • FLOW normal document flow

The four questions. Every listing on every category page answers the same four, in the same order: Do I qualify? What do I bring? How do I apply? Where and when? Learn the pattern on the first listing and the twelfth takes ten seconds. The repetition is by design.

Component inventory — what I build, what I already own

Done before estimating hours. Seven of the ten components on these wireframes already exist in my library and are reused, so only three are billed as new work. That is where the estimate dropped from 116 hours to 92.

  • Built new for this project — 16 hours
    GRID .answers — the four questions, 2×2 then stacked. New.
    FLEX .where-block — label-and-value rows, with the call-first flag. New.
    FLOW .checklist — tick boxes plus a print stylesheet. New.
  • Added in Assignment 8 — visual layer
    FLOW .hero-band — original SVG of Mount Sentinel and the Clark Fork. 1.4 KB.
    FLEX .need-icon / .title-icon / .call-icon — inlined SVG, 2.8 KB for all sixteen.
    FLEX .brand — open-door mark, original, inlined beside the wordmark.
