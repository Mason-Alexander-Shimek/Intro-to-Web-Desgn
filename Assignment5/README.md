# A Setting for a Cyberpunk TTRPG Campaign, Assignment 5

A lore reference for the cyberpunk tabletop campaign I run, built to look like a public access terminal in the city it describes. This week the colour palette was rebuilt around value rather than hue, every image was redrawn and optimised, the four duplicated page themes collapsed into CSS variables, the factions page became a Grid, and the whole site got a breakpoint for small screens.
