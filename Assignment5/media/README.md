# media

Audio and video assets for components live here.

The lesson's `<audio>` and `<video>` elements both take a `src` pointing at this
folder, for example:

```html
<audio controls>
  <source src="media/example.mp3" type="audio/mpeg">
</audio>
```

Keep files compressed and only as long as they need to be, and always leave the
`controls` attribute on so a visitor chooses when sound starts.
