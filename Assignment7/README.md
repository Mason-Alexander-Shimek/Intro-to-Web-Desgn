# Assignment 7 — Vallam Lore Reference

A lore reference site for an eldritch mystery campaign set on Morphe, Anno 1926.
Built from a 69-page source document: 22,000 words, 35 art assets, and one 5333×8000 city map.

## Pages

| File | Part | Holds |
|---|---|---|
| `index.html` | Home | Five gateways, the full city map, an epigraph |
| `world.html` | The World | Morphe, its day and moon, climate, the Nihil Oceans, the continents, the two religions |
| `dominion.html` | Fairbourne | The founding, Crown and Parliament, the Dominion, the Great War |
| `vallam.html` | Vallam | Culture, prohibition, immigration, the map, 10 located neighbourhoods, Vallam County |
| `factions.html` | Factions | 23 organisations across government, press, civic, academic, cultural, and the Congregation |
| `houses.html` | Houses | The nine families of Aldenmere, and seven criminal organisations |
| `wireframes.html` | — | The page wireframes drafted before the build (Module 7 deliverable 1) |

## Components

Built on the ComponentLibrary pattern — HTML structure, CSS rules, and purpose-based content.

**Flexbox** (one-dimensional): `.site-nav`, `.entry-row`, `.crest-tile`, `.place-tile`,
`.dossier-row`, `.gateway-card`, `.tile-strip`, `.site-foot`

**Grid** (two-dimensional): `.layout` (rail + content), `.gateway-grid`, `.crest-index`,
`.place-index`, `.place-split` (locator column + prose column)

**Flow**: `.lore-section`, `.figure-band`, `.pull`, `.cat-head`

### Choosing between them

Every repeated block was measured before a component was chosen, because that is the
mistake Assignment 5 made and the postmortem recorded.

| Content | Length | Component chosen |
|---|---|---|
| Faction / family entries | 131–305 words | `.entry-row` — full width, one per row |
| Neighbourhoods | 308–1250 words | `.place-section` — long-form, locator in its own column |
| Index tiles (names + crests) | 1–4 words | `.crest-index` / `.place-index` — Grid, uniform |
| Home gateways | 5 cards | `repeat(5, 1fr)` — counted; auto-fit at 212px orphans the fifth |

Uniform content goes in a Grid of cards. Variable-length content does not — it gets a full-width
row, so nothing stretches to the height of the longest entry.

## Theme

Roles live in custom properties, so a page's accent is set once and inherited rather than
fought for with specificity:

```css
:root       { --hue: var(--gold); }
.page-world { --hue: #5fa093; }   /* ocean  */
.page-houses{ --hue: #a184cc; }   /* violet */
```

`--void` `--panel` `--rule` `--bone` `--muted` `--hue` `--glow`.
Typefaces: Cinzel (display), Josefin Sans (labels), EB Garamond (body).

## Images

- **Emblems** — white line art knocked out to transparency (alpha from luminance) so they sit on
  any dark surface, then quantised to 64 colours. 4210 KB → 1595 KB.
- **Banners and scenes** — sepia photographs, resized to 1500px, progressive JPEG.
- **Map locators** — cut from the source map by grid reference. The mapped area runs
  x 166–5166, y 166–6833 over 18 × 24 cells of 277.8px, which is why `J14` lands on the
  Confluence and not near it.

## Testing

`audit.py` measures the rendered pages rather than reasoning about them: horizontal overflow,
contrast against the real painted ancestor, heading order, and missing `alt`.

At 1400px and 390px, all six pages: **no overflow, no heading skips, no missing alt text, and
every text/background pair meets WCAG AA** (4.5:1 body, 3.0:1 large).

## Known limitations

- `.crest-absent`, the diamond shown where an organisation has no emblem, measures 2.46:1. It is
  `aria-hidden` and carries no information, so it is decorative rather than text — but it is
  below AA and that is a deliberate exception, not a pass.
- Two of the nine families, **Fairchild and Rajiv**, are the only entries whose crest assignment
  rests on position alone; the others were confirmed against the source text (the Fairchild owl
  is named in its own paragraph).
- There is no search. With 82 sections the sticky rail and the crest and map indexes carry
  findability; a client-side filter would be the next thing to add.
- Fonts load from Google Fonts over the network. Offline, the stack falls back to Georgia and
  Gill Sans, which changes the look but not the layout.
- Content is generated by `build_site.py` from `lore.json`. Editing the HTML by hand works, but
  a rebuild overwrites it.
