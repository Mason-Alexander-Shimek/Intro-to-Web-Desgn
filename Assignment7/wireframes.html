Missoula Resource Finder — Page Wireframes

Five pages: one start page that routes by need, plus four category pages, exactly as the proposal scoped. Every block is a named component. Tags mark which layout system holds it together. Drawn at phone width first, because the proposal promises phone-first.

  • FLEX one-dimensional row or column
  • GRID two-dimensional, auto-fit columns
  • FLOW normal document flow

The four questions. Every listing on every category page answers the same four, in the same order: Do I qualify? · What do I bring? · How do I apply? · Where and when? Learn the pattern on the first listing and the twentieth takes ten seconds. That repetition is the whole design.
