# A Setting for a Cyberpunk TTRPG Campaign — Assignment 6

The final week of the project. Site map, last component decisions, quality testing, and the refinements that testing turned up. The three cards on the homepage used `display: inline-block`, which sits each one on its own text baseline, so their bottom edges finished at three different heights.

I think for my final project, unless I find something more entertaining in a future project, I want to work on a site similar to this, but for a Call of Cthulhu-type game more than DnD I may be running next year. I want to try and do the color theory again, but more worked into the words themselves rather than the pages, as the system that game uses follows more of a skill system like Disco Elysium. It'd also be a nice challenge to try and make something more stylized for the 1920s, with fluff and patterns and stuff, as the existing CRT format helps with simplicity, but a final project probably needs more than what I've got here. I also could have done a bit better with the visual aides, and I think a ground-up sort of remake would go a ways in correcting that. We'll see what's transferrable when we get there, though.
